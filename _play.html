Testing Iron Tide ONLINE solo (no friend needed)

  1. Click “Open ×2 for Online” above (or open /games/iron-tide/ in two windows).
  2. In window 1: PLAY ONLINE → Create Room → note the 4-letter code.
  3. In window 2: PLAY ONLINE → Join Room → enter that code. (Or just hit Quick Match in both windows — they’ll auto-pair.)
  4. Place ships in both, then play — you control both sides. Watch the 15s timer auto-pass a stalled turn.

Start the server first: run play-games-local.bat (in the Claude Claw folder), or in a terminal: cd "C:\Users\TestRun\Claude Claw\forgeflow-games" && python -m http.server 8788 — then open http://localhost:8788/_play.html
