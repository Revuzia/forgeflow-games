How “Play vs People” works

  1. Play vs People opens the game straight into the online lobby.
  2. With a friend: one picks Create Room and shares the 4-character code; the other picks Join Room. (Or both hit Quick Match to auto-pair.)
  3. No friend handy? Use “open two tabs” under a game to play both sides yourself — Create in one tab, Join (same code) in the other.
  4. A 15-second turn timer auto-passes a stalled turn. Chess online is Elo-ranked.

Start the server first: run play-games-local.bat (in the Claude Claw folder), or in a terminal: cd "C:\Users\TestRun\Claude Claw\forgeflow-games" && python serve_nocache.py 8788 — then open http://localhost:8788/_play.html. (No-cache server: edits show on a normal reload.)
