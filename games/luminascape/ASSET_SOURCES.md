## Biggest Untapped Sources (recommended, in priority order)

1. **Quaternius (~2,500 CC0)** — the single best *untapped* fit. Direct-ZIP, zero attribution, and the low-poly nature/animal art style is a near-perfect match for LuminaScape. Highest ROI; wire next.
2. **Freesound CC0 subset (714k total)** — we already do ambient audio (task #18); its CC0 filter + OAuth API is the cleanest path to weather-reactive nature SFX (thunder, water, wind, crickets) beyond Kenney's limited audio.
3. **KayKit Complete (~1,000 CC0)** — modular village/nature/character GLBs, CC0, animated. Manual itch download is the only friction.
4. **Smithsonian 3D (~2,000+ CC0)** — realistic plant/rock/heritage props via API for the "realistic" half of "cozy realistic."
5. **Fab / Megascans — time-sensitive**: photoreal foliage/rock is *free to keep* only through end-2026 (Fab Standard license, not CC0). If we want any photoreal detail assets, claim them before the window closes; note licensing is Fab-Standard, not public-domain.

**Cleanest CC0 + easiest download tier (prioritize these):** Kenney, Poly.Pizza (API), Quaternius, Poly Haven (API), ambientCG (URL API), Smithsonian (API). All allow scripted/direct download with no attribution and no gated login — ideal for a `_LAZY` auto-wire batch.
