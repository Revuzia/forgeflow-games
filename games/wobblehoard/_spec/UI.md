## 1. Owner decisions
1. No font files or outside assets (`font-src 'none'`, strict CSP, CSSOM-only styles): a drawn jelly display type (5) + a named system stack. 2. Queue: after the shell stage. 3. A real toolbar, not a "Toys" button: tools always visible as icon buttons in one dock, the active one clear, labels on hover / focus / live region, one-key shortcuts, options bar attached. 4. Squishy display type: an original jelly alphabet as SVG paths in code, real text in the DOM. 5. Parity with BLOCKTOOTH and DYEFIELD (2). 6. UI finished BEFORE publication on forgeflowgames.com. 7. Toys is RESERVED for the pets update ("real toys like a ball, a stick"); the old tray is TOOLS (Hand, Cut, Snap, later Stamp, Roll). Pets come later as hidden kit components (not mounted until the feature exists): `ItemShelf`, `Caption`, groups `Play` (Toys shelf, key `T`) and `Care`, a mood slot, a Settings "Voices" switch behind `FEATURES.voices`.

## 5. THE SQUISHY DISPLAY TYPE
**Authoring: stroked skeletons.** Each glyph is ONE centre-line path on a cap-100 grid (y 0 top, 100 baseline), x 10 to w-10, integers, M L C Q only, advance w+8, drawn five times with round caps and joins: shadow (ink .35, down 7), outline (ink, 30), shade (darker tone, 20, down 4), body (tone, 18), highlight (white .55, 5, up-left). Seed: `I M30 10V90`. **The v2 seed for A is INVALID [R08]:** body 18 leaves a clear counter on 5 of 100 rows (y 48..52, <= 2.5 wide), the 30 outline none (computed 2026-10-08); 30 / 18 are start values, A needs more width, a lower bar or a lighter stroke.
**Gate [R08]:** B2's first deliverable is a glyph sheet (all glyphs at caps 24 / 36 / 56 / 120, every tone, on panel and white); V1 signs it BEFORE anything uses the type. Counters of A B D O P Q R 4 6 8 9 0 keep >= 2 px clear at cap 24 and >= 4 px at cap 36 (raster test, K14). **Optical sizes:** `sm` (cap 24) outline 22, body 14, 3 passes (no shadow, shade, gradient); `md`+ 5 passes. **Finish:** one `linearGradient[gradientUnits=userSpaceOnUse]` (y1 5, y2 95) per tone and tier in the hidden defs svg, body pass only, stops by `setAttribute` (CSP-safe; an `objectBoundingBox` gradient does not paint on a straight `I`). **Fallback** if V1 does not sign: system 800 with `paint-order: stroke fill`, 4 px ink stroke.
**Set:** A-Z (lower case folds up), 0-9, `. , ! ? ' - : / + % & # ( )`, space; others in system 800. **Budget:** glyphs 8 KB raw (was 3.5; G0b has about 260 KB gzip free), helper 3 KB gz, CSS 1.8 KB, boot-card SVG 2.6 KB, <= 120 glyphs on screen.
**API** (`ui/jelly/jelly.ts`): `jelly(text,{size:'sm'|'md'|'lg'|'xl', tone:'amber'|'cream'|'coral'|'lagoon'|'plum'|TierName, tag, live?})`, `setJelly`, `jellyWidth`, `fitJelly` (floor 14), `pokeJelly`, `ensureJellyDefs()` (a hidden `<svg>` of `<symbol id="jg-X">`; a glyph is five `<use>`). **Wobble:** title lockup and brand only (`jt-idle`, 3.4 s); poke = WAAPI squash + `ui('tick')`; Calm: no idle, poke = one 120 ms highlight.
**Accessibility:** real text in a `.sr-only` span inside the element (a real h1 / h2 / h3 names itself from it); SVG `aria-hidden`. Under `forced-colors: active`, `prefers-contrast: more`, no JS or missing defs the SVG is `display:none` and system 800 shows (W8). One h1 at any moment. **Where:** lockup, brand, panel headings, tier names, big numerals.

## 7. Motion, sound, haptics, modes
- **Motion [R16]:** animate `transform` and `opacity`; small `contain: paint` exceptions (progress and merge-label fill by `clip-path` / `background-position`, under 200x60 px; gloss). Panels 220 ms ease-out, sheets 360 ms. **Calm (`body[data-calm]`, `prefers-reduced-motion`):** `--t-move: .01ms`, `--t-fade: 140ms`; no idle wobble, breathing, squash, shake or moving gloss; no flash above 3 per second.
- **UI sound:** `SquishAudio.ui?(p:{kind:UiKind; calm?})` additive and optional (`audio/ui.ts`); Settings `uiSounds` (default on). 12 soft sine / triangle kinds on one pentatonic scale: `tick press select on off open close back error toast trophy sticker`. Peak <= -18 dBFS (`stats().peak` <= 0.126); gap 40-400 ms per kind; mute-aware; dropped before unlock and in ceremonies (except `toast`, `trophy`). ONE delegated listener (`ui/uiSound.ts`) maps classes and roles to kinds; `data-sound="none"` opts out.
- **Haptics** (`input/haptics.ts`, new `uiTap`; coarse pointer + Settings): 8-12 ms taps; a double pulse on error, trophy, ready.
- **prefers-contrast: more:** no backdrop-filter, solid panel, 4 px ring, gloss and jelly off. **forced-colors: active (W8):** a real 1px border on every control; states in `Highlight`, `HighlightText`, `ButtonFace`, `ButtonText`, `CanvasText`; no `-webkit-text-fill-color: transparent` (`styles.css:89`, `:436-448`); on / off carry a tick or word.
