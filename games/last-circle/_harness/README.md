# Last Circle browser gates (`_harness/`)

Dev-only (deploy_game.py DEV_ONLY_DIRS skips `_harness`). Every gate prints one verdict table, writes JSON to `_harness/_reports/`,
and exits **0 pass / 1 fail / 2 could-not-judge** (environment: server refused, rAF starved on a check that needs rAF, browser
never started, a match load still running past `--load-timeout`). An exit 2 is re-run, never counted as a pass.

Common flags (common.py): `--disk` serves games/last-circle READ-ONLY from the working copy through page routing (no server; the
repo root is never served), `--rev <git rev>` serves the game as committed at that revision (a frozen build while lanes edit the
tree), `--base <url>` (default `http://127.0.0.1:8790/games/last-circle/index.html`), `--headed` (default headless; pointer lock
works headless), `--gpu d3d11|dgpu|swiftshader`, `--load-timeout` / `--boot-timeout`. View frames are STEPPED
(`common.step_frames`, or `__LC__.stepFrames` when lane L4 lands it), so nothing waits on the box's starved rAF. Matches are
started by `common.start_match`: `__LC__.startMatch()` -> the lobby -> a REAL Enter, so W.phase really reaches drop/match.
