## Build order
Implement in this order — most of the L1–L2 kit is already coded, so ship the cheap wins first, then build 5 new primitives.

PHASE 0 (free reuse): escape_sim.js already implements every L1–L2 ability. Knight bash (kind:"bash"), barbarian crush (kind:"crush"), sorceress fire+frost bolts, rogue knife+poison, and the burn/poison/frost/stun status system all exist in playerSpecial()/playerFrost()/applyStatus() (~lines 546–600). Charm and weaponTier damage scaling is already in the dmg formula. So step one is NOT combat code — it's the slot/level scaffolding: (a) add p.level + a per-slot cooldown set (p.rT, p.spaceT, p.fT) alongside the existing p.specialT/p.frostT; (b) a CLASS_ABILITIES registry keyed by class→slot→{unlockLevel, cd, mana, handler}; (c) gate each handler on p.level >= unlockLevel; (d) in escape.js, split the input flags — currently KeyF is just a _special alias and KeyR is _frost (lines 602–603); repoint to distinct _abilityR/_space/_abilityF so R/Space/F are independent slots. This alone makes every class's first two abilities level-gated with zero new mechanics.

PHASE 1 — Movement primitive (highest value, one primitive powers 4 abilities): a shared dash/teleport helper in the sim = impulse-move along p.yaw with moveCircle() collision, optional i-frame window (p.invulnT), optional teleport-through (skip collision). Drives Knight Shield Charge, Barbarian Leap Slam, Sorceress Arcane Blink, Rogue Shadow Roll. Space slot for all four. Deterministic + MP-safe since it's just position deltas already synced.

PHASE 2 — Self-centered AoE + shockwave FX: reuse meleeHits() with a full 2π arc and a self-origin radius query for Barbarian Whirlwind, Knight Earthshatter, and the landing pulse of Leap Slam. Add a "shockwave" render event (escape.js already has cast/bash/crush FX plumbing to copy). Knight War Cry adds two small systems: a taunt flag on enemy AI (force e.target = knight for a duration — hook in stepEnemy target-select ~line 634) and a self damage-reduction buff timer read in damagePlayer().

PHASE 3 — Chain Lightning (new elem): new bolt behavior — on hit, scan for nearest N un-hit enemies within radius and re-emit an arc to each with 20% falloff. Add elem:"lightning" (bolt color default is already purple 0x8f6bff in escape.js line 735 — add a cyan-white case) and a 0.3s micro-stun reusing the existing e.stunT. Sorceress F.

PHASE 4 — Player buff timers: Berserker Rage needs a p.buff block {atkSpeedMul, dmgMul, moveMul, vulnMul, t} read in playerMelee cd, the dmg formula, movement speed, and damagePlayer. Reusable for future gear/blessings.

PHASE 5 — Multi-hit ULTs: Rogue Fan of Knives = spawn 5 poison bolts in a yaw spread (trivial reuse of the bolt push in playerSpecial). Rogue Shadowstrike = Phase-1 teleport-to-target + 3 queued melee ticks + poisoned-target damage check. These are last because they compose primitives from Phases 1–4.

Elements coverage: fireball / frost shard / chain-lightning all live on the Sorceress (owns the caster fantasy); poison cloud is the Rogue's whole kit; martial shockwave/whirlwind/leap carry Knight (defense+control) and Barbarian (throughput+AoE). Mana discipline: only the Sorceress spends mana; martials and the Rogue are cooldown-only, preserving the current sim's identity split. Source of truth read: escape_sim.js CLASSES (lines 33–56), combat handlers (509–600), status system (496–507); escape.js input (lines 572–637) and clip/FX map (462–476).
