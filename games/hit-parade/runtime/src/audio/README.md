# HIT PARADE audio (lane AUDIO)

CONTRACT §9 + §9.1. One integration surface: `createAudio()` in `index.ts`.

## Wiring (game.ts / menus)

```ts
const audio = createAudio();                 // nothing fetched yet; the first gesture unlocks + fetches the UI sprite
audio.music('menu');                         // title / main menu ('select' on character select, 'results' on results)
audio.ui('move'); audio.ui('confirm');       // menu sounds (a click / key through ui() also unlocks)
// a bout loads:
audio.bout({ fighters: [p1, p2], stage, mode: cfg.mode, local /* 0|1, -1 local 2P */, sfxNames: m.tab.sfx });
audio.preload();                             // sfx + crowd sprites (low priority, after the stage GLB)
// every rendered frame, with the NEW (deduped) events:
audio.events(newEvents, readMatch(m), [readFighter(m, 0), readFighter(m, 1)]);
audio.setPaused(true);                       // pause card (UI sounds stay, music softens)
audio.bout(null); audio.music('results');    // leaving the bout
audio.setSplatter(settings.gore);            // 'splatter' | 'sparks' | 'confetti'
audio.setVolumes({ master, music, sfx, crowd, voice });
__HP__.audio = () => audio.stats();
```

The stage music starts by itself on the first round intro (from the ROUND_INTRO event or the `intro` phase); KO / match
end duck and fade it. `announce('3'|'2'|'1'|'go')` is there for the online start-sync countdown.

P2 (CONTRACT s9.2), all automatic from `bout()` - game.ts needs no change:
- `bout()` builds a bout context (`boutContext()` in router.ts) from `loadGameData()` (or `AudioBout.data`): the fighters'
  move tables by moveId, the stage's stages.json `music` / `ambient`, the heckle objects and goon kinds.
- music: `brawl` / `heckler` cues for the bonus rounds (`music('stage')` picks them from `bout().mode`); stage music by
  stages.json `music` when it resolves, else the stage id; RICKY -> boss, THE FREAK -> miniboss.
- stage ambience loop per stage on the crowd bus (rooftop adds thunder one-shots); it recedes as the crowd gets loud.
- projectiles by `projectile.clip` (PROJ_SOUNDS: wind-up from the move's frame-0 SFX_CUE, release on PROJ_SPAWN, impact on
  PROJ_HIT); weapon layers (WEAPON_RULES: Boneyard cleaver, Krane baton / riot shield, Ricky mic-cane) on HIT / BLOCK.
- PRIME TIME: open / finish / close stingers + per-cue beats (CINE_BEATS) on `MatchSnap.cinematic.frame`, rollback-safe.
- BRAWL BREAK / HECKLER TOSS per CONTRACT s28.4 (goons 8 + slot with their own voice bank, crowd objects 2, object landing
  sounds, SCORE register); SIM P2 extra events (EVX: CATCH TELEPORT PHASE BALL INSTALL) in EXTRA_EVENT_SOUNDS.
- online lobby UI cues: `ui('search'|'found'|'join'|'leave'|'ready'|'reveal'|'code'|'rematch'|'disconnect'|'countdown')`.

## Files

| file | what |
|---|---|
| `index.ts` | `createAudio()`: gesture unlock (iOS touchend/click), tab-hidden suspend, per-frame router update, `stats()` |
| `engine.ts` | WebAudio: buses (sfx / voice / crowd / ui / music), 28-voice pool, sprites sliced per variant, native-loop music with crossfades, ducking, pause, limiter meter, Ogg-Opus with AAC twin fallback |
| `router.ts` | events + snapshots -> sound commands; `EVENT_SOUNDS` covers every `EV` type (typecheck-enforced); voice banks per fighter; SFX_CUE vocabulary; crowd bed from SHOWTIME + excitement |
| `types.ts` `voices.ts` `seam.ts` | public types; voice stealing; loop-seam crossfade (shared with the probe) |
| `manifest.ts` `CREDITS.json` `assets/` | GENERATED by `build/build_audio.py` - never hand-edit |
| `build/build_audio.py` | the generator (sources -> mastering -> Opus + AAC -> manifest, credits, `build/kit_report.json`) |
| `build/extract_packages.py` | unpacks the selected audio of the local Unity packages into `F:/games/unity-assets/` (the Evil Mind music of the bonus rounds was already there) |
| `build/lab_check.py` | headless Chrome run of `runtime/lab/audio.html` (decode every asset, play every sound + cue, bout demo) |

## Gates

- `node _harness/probe_audio.ts` - files, budget, seams, loudness, AAC twins, EV coverage, vocabulary, registry, credits, router on a real bout
- `python runtime/src/audio/build/lab_check.py` (dev server on 5328: `HP_FROZEN=1 npx vite --port 5328 --strictPort`)
- `python runtime/src/audio/build/build_audio.py` exits 1 when a mastering gate fails (decoded true peak > -1 dBTP,
  lead-in > 8 ms, sub-dominated impact < 25 % in 150 Hz-4 kHz, loop seam > 1.5x, payload > 12 MB)
